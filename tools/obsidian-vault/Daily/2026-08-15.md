# 2026-08-15

## Work log

- Инициализирован явно разрешённый frontend boundary `frontend/uikit/` полным Spacewhy liquid-glass UI kit.
- Существующие `backend/`, `deployment/`, `frontend/admin/` и `tools/` сохранены; placeholder `frontend/uikit/.gitkeep` заменён приложением.
- При переносе исключены `node_modules/`, `.next/`, `.git/`, `.DS_Store` и локальные environment-файлы.
- В `frontend/uikit/` успешно выполнены `npm ci`, `npm run lint` и `npm run build`; production build сгенерировал 121 маршрут.
- Legacy lockfile Minimals сообщает 73 `npm audit` advisory; автоматический breaking upgrade не применялся в задаче публикации.
- Реализация зафиксирована коммитом `55283e6`.
- Устранена деградация навигации: глобальный `ProgressBar` создавал новый `MutationObserver`, повторные listeners для всех ссылок и вложенные `history.pushState` proxies без cleanup. Реализация заменена одним delegated click listener с корректным cleanup и завершением по `pathname`.
- Полноэкранный Framer Motion splash на каждом route loading заменён лёгким верхним progress indicator с `prefers-reduced-motion`; motion runtime сокращён с `domMax` до `domAnimation`.
- У статических glass surfaces удалены ненужные paint-heavy transitions, а интерактивные кнопки используют только короткие `transform`/`border-color` transitions.
- Обнаружено, что demo data routes возвращали HTML вместо JSON, а исходный публичный Minimals API больше не обслуживает эти endpoints. Добавлен локальный Axios demo adapter для Product, Blog, Mail, Chat, Kanban и Calendar; remote demo API теперь только opt-in через `NEXT_PUBLIC_USE_REMOTE_DEMO_API=true`.
- Проверки после исправления: `npm run lint`, production `npm run build` на 121 маршрут, browser smoke для component page, tabs, settings drawer и glass controls без console errors.
- Исправление производительности зафиксировано коммитом `fa08f4b` на ветке `codex/fix-uikit-navigation-performance`.
